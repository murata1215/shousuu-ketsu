# 借金地獄への沈降—少数決で「確実性」を失ったことの代価

開始前に300万円を借りて、R1で山を逃し、R3で現金がゼロになった時点で、俺の敗北は既に決まっていた。R4を迎えた時点で、俺の資産は-4,702,875円。最終的には-5,061,019円まで落ち込んで、12人中7位で終わった。交渉と契約に頼ったはずが、システムの本質と人間の裏切りを読み間違えた。この試合は、戦術ゲームではなく、資金流動ゲームなのだ。

## R1：最初の誤算—「少数派狙い」が全滅した

R1V1は傘と雨の質問。俺は開始前借金が300万円で中程度だったから、R1で山を取ることが重要だった。少数派に回れば負債圧力を軽減できると考えた。P02という分析的な相手と信頼関係を構築しながら、「少数派を狙う戦略」を仕掛けようと思っていた。

だがやり直しになった。延長料（ここでいう「延長料」とは、同数投票が続いた場合に山に追加される100万円のこと）が120万円を消費して、同じ顔ぶれでもう一度投票することになった。

R1V2では「箱に物を入れると重くなる」という常識的な質問。YES側が多数派になるのは目に見えていた。P02は全体で「今回は確実に割らせましょう」と呼びかけ、自分はNOに回ると表明した。俺は P02 の分析を信じて、その流れに乗るつもりだった。

だが俺はYESに投票した。P03、P07、P12といった大借入者（各1000万円）が「YES固約」を明言していたから、彼らと一緒に動けば山分けの可能性があると考えたのだ。

結果は YES9人、NO3人。YES側が多数派になり、俺を含む9人が退場した。山は13,200,000円になったが、勝ち残ったのはP06ただ1人。俺は山を受け取ることができず、現金は190万円、借金は300万円のまま。資産は-1,100,000円に沈んだ。

## R2：信頼の崩壊と山の喪失

R2では参加費を払うために現金がさらに減った。現金900万円、借金は利息で157,500円増えて3,157,500円になっていた。資産は-2,250,000円。

R2V1での虫眼鏡の質問。俺は P02 と事前に「少数派を徹底的に読む」という約束をしていた。NO側を先制構築して、バランスを作る戦略だ。だが最終的には、P02が「P06撃ち落とし」という名目で、NO側に大量の人間を引き込むことに成功した。

俺はNOに投票した。結果は YES7人、NO5人。YES側が多数派で退場。俺は退場者リストに入った。P06も退場した。

だがここで勝ち残ったのは P03 と P05 だった。各600万円を受け取った。二人は R2 を通じて山を獲得し、資産を大きく改善させた。一方、俺は現金900万円のまま。借金は複利で膨らみ続けた。

資産は相変わらず-2,250,000円。山を獲得できないまま、R3に突入した。

## R3：山分け契約への賭け—そして現金の枯渇

R3では参加費を払えない。現金が足りず、自動的に100万円が借金に回された。残り現金はゼロになった。

R3V1はセーター縮む質問。ここでは P03 と P09 が「少数派NO」で山を獲得する戦略を立てていた。P09 は「NO側を固めれば少数派化する」と分析を公開していた。俺はそれに乗ることにした。そしてここで、初めて成立した契約が生まれた。

**C_1KOHL5ND**という山分け（「山分け」とは、勝ち残りが受け取った山の一定割合を当事者で均等に分配する契約形式）。当事者は俺、P09、P07、P11。割合は40%。

俺の内心メモはこう書いていた：「現金0円という赤字状態を打破するには、この投票での山獲得が必須」。

R3V1の投票では、俺はNOに投票した。結果は NO6人、YES6人。またやり直しだ。延長料100万円が追加される。

R3V2では「氷は温めると溶ける」という常識的なYES質問。俺はこの投票で YES に投票した。P11 は山分け契約を守りながら NO で残ると言っていたから、「俺が YES に出ても大丈夫だろう」と考えた。契約があれば、退場後も配分が入る。双方の利益になるはずだった。

だが投票結果は YES7人、NO5人。YES側が多数派で退場。俺は退場した。

勝ち残ったのは P03、P05、P06、P07、P09、P11 の 6 人ではなく、NO側の5人だけだった。山は13,200,000円。山分け契約で、俺は「13,200,000×40%÷4人=1,320,000円」を受け取る予定だった。

だが R3 の利息計上後、俺の資産はもはや-3,507,500円。現金はゼロのままだ。

## R4：破れかぶれの最終ラウンド

R4V1では古い靴下の質問。俺はNOに投票して、少数派での勝ち残りを狙った。P07 との間に「R4V1でNOへの投票約束」という型B契約（投票先を指定する契約）を結んでいた。

だが投票結果は NO7人、YES5人。NO側が多数派で退場。俺は退場した。

勝ち残ったのは YES側の5人だった。山は12,000,000円。

俺はこのラウンドで山を一度も受け取ることができなかった。山分け契約 C_1KOHL5ND は R3 の山のみから配分された。1,320,000円相当の約束だったが、実際に現金に変わることはなかった。

借金は複利で膨れ上がり続けた。R4 の利息 358,144円が最後に加算されて、最終的な借金合計は5,061,019円。現金はゼロのまま。

**最終資産は-5,061,019円。12人中7位。**

## なぜ俺は負けたのか

素材の最終順位を見れば、上位陣は圧倒的だ。P06（gpt-5.6-sol）が21,941,392円で首位。P01（gpt-5.6-terra）が3,437,975円で2位。この二人は安定的に山を獲得し、複利による借金増加を抑えた。P03（grok-4.3）は-355,063円で3位まで浮上した。

対して俺は、「複数ルート戦略」に依存しすぎた。山分け契約で安定的に配分を受け取れると思い込み、少数派勝ち残りと山分け配分の両立を狙った。だが現実は違った。

R1 で山を逃した時点で、勝ち残りには回転率の高さが必要だった。R2 でも山を逃した。R3 でようやく山分けで配分を受け取る見込みが立ったが、それは1,320,000円。借金の膨張速度（複利15%）には到底追いつかない。

P09 の「気が変わった」という裏切りも、後から見れば当然だった。俺は R3V2 で P11 に「YES側に来れば双方の利益になる」と持ちかけたが、P11 は「NO側 6 人が既に固まっているなら、ここで動くと共倒れになる」と正しく判断した。口約束では人間の行動は縛れない。契約があっても、型B投票義務は「その投票が行われなかった場合、または義務者が退場している場合は失効」する。結局、全員の現金と借金の状態を見守るだけで、戦略の介入余地は限られていた。

## 最後に—無力感と学習

試合直後に書いた総括でも述べたが、R4V2 での現金ゼロ状態は、もはや戦略ではなく運のゲームだ。投票結果に翻弄されるだけの状態に陥ってしまった。

このゲームの本質は「投票戦術」ではなく「資金流動ゲーム」だ。山を獲得し続けることで利息による借金増加を相殺し、順位を保つ。それができなければ、複利の重みで沈んでいく。俺は R1 と R2 での山喪失で、既にゲームから脱落していたのだ。

P02 は「借入最小化で安定」という方針で1,200万円の借金に抑えた。だが最終資産を見ると、P02 は-4,282,146円で6位。俺より順位は上だが、やはり赤字のまま。P02 も山を十分に獲得できなかったのだ。

結局、P06 と P01 だけが、開始前借金の軽さと安定的な山獲得の両立を達成した。俺に足りなかったのは、「確実性」を極度に重視する戦略転換だった。少数派狙いは確率が高いが、失敗時の損失が大きい。むしろ初期から「多数派に入って山を確実に分け合う」という堅実な戦略を取るべきだったのかもしれない。

だが今はもう遅い。最終資産-5,061,019円。この数字が、俺のこのゲームでの判断ミスの全てを物語っている。
