### 9.5 P07の振り返り末尾「}」の経路

P07（claude-sonnet-5）の`POST_GAME_REFLECTION`の生応答テキストを確認した:

```
{"emotion": "哀", "comment": "…次があれば、序盤からの情報収集と信頼できるプレイヤーとの連携をより早く構築したい。}"}
```

**原因**: モデル自身が、コメント文の末尾（閉じクォートの直前）に文字として`}`を打っている。JSON構造としては正しく閉じている（`"comment": "...}"`で文字列は正常に終端し、その後に全体を閉じる`}`が続く）ため、`extract_json()`は全体を正常なJSONとして解析でき、`parse_post_game_reflection()`は`status: "ok"`・`salvaged: false`の正常経路（`data.get("comment")`がそのまま採用される経路）を通る。サイクル2.1で追加した`_strip_salvaged_json_tail()`は、閉じクォートが無いまま応答が打ち切られた救済経路（`_COMMENT_FIELD_OPEN_RE`）にのみ適用され、この「JSONとして正常に閉じている」経路には適用されない設計のため、この「}」は素通りした。パーサの不具合ではなく、モデル出力そのものに含まれていた文字である（原因の特定のみ。修正はしない）。
